# Entity frontmatter schema & reference syntax

Type: grilling
Status: open
Blocked by: 01

## Question

What exact frontmatter fields does each Entity type carry (Theme, Project, Deliverable, Person, To-do, Glossary Term, Note), which are required, and what are the status enum values? How is a reference written: bare identifier in a frontmatter field (`project: data-migration`), a wiki-link (`[[data-migration]]`), or both, and may the Markdown body contain references that count as Tags? How are multi-valued fields (Tags to People/Stakeholders) expressed, and how are a Person's kind and Manager recorded?
