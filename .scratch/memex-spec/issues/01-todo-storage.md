# To-do storage: own file or inline checkbox?

Type: grilling
Status: open
Blocked by:

## Question

How is a To-do stored on disk? Options include: one file per To-do (`todos/<id>.md` with owner/requester/status/due in frontmatter); Markdown checkbox lines inside any Note with inline metadata (e.g. `- [ ] Send deck @alice ^due:2026-12-01`); or a hybrid (checkbox lines that the app can promote to files). Decide the representation, how Owner/Requester/status/due/linked Entity are expressed, how done To-dos are kept or archived, and what that means for editing a To-do from a meeting Note vs. from the Person View.
